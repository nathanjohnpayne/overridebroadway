## Standard Compliance Notes

- **`out/` present:** Next.js static export artifacts. Never edit directly. `check_dist_not_modified` CI script checks `out/` (not `dist/`).
- **No `dist/`:** This is a Next.js project; output goes to `out/`. The `check_dist_not_modified` script is customized for this repo.
- **No Cloud Functions:** Pure static export. Firebase Hosting serves the static Next.js output.
- **`.cursor/rules/deploy.mdc`:** Valid Cursor AI rules format — not instruction prose. The `check_no_tool_folder_instructions` CI script excludes `.mdc` files.
- **`tests/` placeholder:** No automated unit test suite. The root `tests/` directory is a standard placeholder per the AI Agent Tooling Standard.
- **No `.claude/worktrees/`:** No Claude Code worktree state in this repo currently.
- **`scripts/` contains build scripts:** `prebuild.mjs` and `postbuild.mjs` are part of the Next.js build pipeline. `scripts/ci/` is the CI enforcement directory.
